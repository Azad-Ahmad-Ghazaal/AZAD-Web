# AZAD Task/Web Training

Training is staged and verified.

1. Observe a website/task in a controlled browser session.
2. Record the user's goal and the sequence of UI actions.
3. Remove credentials, tokens, cookies, personal data and hidden metadata.
4. Mark the trace as pending.
5. Human verification approves a trace.
6. Approved traces become examples for intent/task planning.

The first MUAG release must not autonomously execute arbitrary learned browser actions or privileged commands.
